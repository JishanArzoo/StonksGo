# StonksGo 📈

A stock trading web application built with **Next.js**, powered by **Alpaca**.

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Better Auth
* Prisma
* PostgreSQL
* Alpaca API

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

> 🚧 StonksGo is currently under development.
